# AR_ProjektArbeit
This repository contains a 3D-Core Unity project with the Vuforia SDK.

## Description
This application is an Android AR application designed as a promotional tool for a fictional museum. It provides information about both the exhibits and the museum itself, serving as an extension of the flyer to generate more interest. There are various interactive features that are used to convey information and allow further interactions with the virtual environment. 


### Controls
The application is fully designed for touchscreens and allows switching between Image Target and Markerless modes. In Markerless mode, the 3D environment can be placed with a tap on the screen, while in Image Target mode, the back of the flyer must be scanned.
